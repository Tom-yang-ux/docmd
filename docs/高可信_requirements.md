# 高可信 Markdown 桌面 EXE 制作流程（原始需求）

> 本文为需求来源文档，DocMD 据此实现。实现范围见仓库根 README。
> （内容即用户提供的 16 章需求，收录留存以便追溯与评审。）

## 1. 固定产品边界
1. 明确目标平台为 Windows 10/11。
2. 明确产品输入：PDF、图片、Word、Excel、PPT。
3. 明确产品输出：含 A/B/C/D 分级字段的 Markdown；原始识别结果；待确认问题清单；用户确认后的最终 Markdown。
4. 明确默认原则：C/D 字段保留在 Markdown；AI 读完整文档后先汇总提问；用户确认前禁止开始后续处理；用户确认后才生成可用最终文件。

## 2. 确定桌面技术路线
1. Python 识别与文档处理核心。2. PySide6 桌面界面。3. SQLite 保存任务/识别结果/确认记录/模型配置。4. PyInstaller 或 Nuitka 打包 EXE。5. 大型模型权重与 EXE 分离：EXE 只含程序与基础依赖，首启由模型管理器下载或导入。

## 3. 设计本地目录与数据结构
为每个导入文档创建唯一任务 ID；保存原始文件副本或路径；按页导出预处理图片；保存每个引擎的原始结果；统一中间结构 JSON；初版 Markdown、确认记录、最终 Markdown；字段级记录（字段内容/类型/页码/坐标/来源图片/各引擎结果/可信等级/冲突原因/用户确认值/确认时间）。

## 4. 制作文档导入模块
桌面拖放和文件选择；识别文件类型；Office 原生文本优先；扫描 PDF/图片/复杂版式走视觉；任务状态「已导入→预处理中→识别中→分级中→等待确认→已确认→已完成」。

## 5. 制作图像预处理模块
PDF 按页转图；页面方向检测旋转校正；检测低清晰/倾斜/阴影/水印/裁切；低质量页生成增强版（去噪/对比度/锐化/局部放大/重新裁边）；原图与增强图并存可追溯。

## 6. 接入视觉识别模型
PaddleOCR-VL 主视觉；MinerU 版式/表格/公式/多栏复核；DeepSeek-OCR-2 第三识别（异常页/冲突字段）；统一输入输出接口；模型启用/禁用、路径、GPU/CPU、并发数配置；显示进度/页码/耗时/失败原因。

## 7. 制作统一文档结构层
多模型结果转同一种内部 JSON；按页/标题/段落/表格/图片说明/公式/关键字段拆分；每块绑定页码/坐标/原图区域；文字基础归一化（全半角/空格/常见 OCR 字符混淆/标点/数字格式）；不擅自改语义或关键数值。

## 8. 制作字段级可信度分级模块
对齐各引擎段落/表格/单元格/公式/关键字段；执行多模型一致性、清晰度、坐标一致、表格结构一致、金额/日期/编号/姓名/公式冲突、业务规则检查；标记 A/B/C/D；关键字段冲突不得自动降级 A/B。

## 9. 生成「待确认 Markdown」
完整 Markdown 不删 C/D；开头写 `document_status: awaiting_confirmation` 与 `processing_gate: user_confirmation_required`；C/D 旁写等级/候选/页码/冲突原因/是否需要确认；文末待确认清单；存 `review_required.md`。

## 10. 接入 AI 阅读与提问模块
AI 配置页（API 地址/模型名/密钥安全/是否上传原图/最大上下文）；把 review_required.md 交给 AI；固定注入规则（完整阅读、汇总全部 C/D、一次性提问、确认前禁止分析/总结/问答/导出/写知识库）；AI 只生成待确认清单不处理业务；提问显示在确认面板。

## 11. 制作用户确认界面
按页码/类型/严重程度列出 C/D；每项显示原图截图/各模型候选/AI 说明/输入框/「候选A/候选B/手动/暂不确认」按钮；支持批量确认；后写入字段记录与确认日志；未确认项不得进入最终文件生成。

## 12. 生成最终 Markdown
确认值回写字段；已确认标记 `confirmed_by_user`；无冲突保留 A/B；删除候选与待确认说明；保留页码/来源/追溯 ID；状态改为 `document_status: confirmed` + `processing_gate: open`；输出 `final.md`；同时输出审计 `evidence.json`（不默认交给普通 AI）。

## 13. 开放后续 AI 处理
仅当 `document_status: confirmed` 才允许总结/问答/报告/知识库/检索/分类等；后续 AI 默认只读 final.md；需核验时可据追溯 ID 打开对应原图区域。

## 14. 制作模型与成本控制
可复制 PDF 优先文本提取；扫描页按页调视觉模型；仅 C/D 页或局部调第三模型；文件内容与结果哈希缓存；同文件同模型同配置不重复识别；本地模型优先云端备用；记录页数/耗时/调用次数/估算成本。

## 15. 制作测试集与验收流程
收集真实样本（清晰 PDF/模糊扫描/中英混排/多栏论文/表格/公式/合同/手写盖章）；人工做正确答案；测试字段级识别率/表格还原率/公式还原率/页码定位率；测试 C/D 是否都被 AI 一次性汇总；测试 AI 是否确认前错误处理；测试确认后是否正确更新最终 Markdown；全部门控通过才发布版本。

## 16. 打包为 Windows EXE
独立 Python 虚拟环境；固定版本；应用图标/名称/版本/安装目录；PyInstaller/Nuitka 生成 EXE；安装器生成安装包；首启执行创建数据目录/初始化 SQLite/检查模型/引导下载导入/检查 GPU/CPU；未装模型时明确可用与不可用功能；干净虚拟机测试安装/模型下载/导入/识别/确认/导出/卸载。
